# Документы витрины в стилистике сайта

Оформленные версии примеров из `showcase/`. Текст и компоновка — авторские, из оригиналов методолога; меняется только оформление. Оригиналы не трогаются.

| Файл | Оригинал | Листов |
|---|---|---|
| `instruction-entry.html` | `Пример инструкции один.html` | 8 |
| `instruction-probation.html` | `Пример инструкция два.html` | 8 |
| `instruction-veteran.html` | `Примеры инструкции три.html` | 8 |
| `company-avatar.html` | `Аватар.html` | 13 |
| `plasma.html` | `плазма пример.html` | 6 |

Рядом с каждым HTML лежит готовый PDF с тем же именем.

## Как устроено

Документы **собираются из оригиналов**, а не пишутся вручную. Скрипт `tools/restyle.mjs` загружает оригинал в браузер и делает следующее:

1. Снимает старое оформление: стили, цвета, рамки, градиенты. Текст и раскладку (колонки, ширины) оставляет.
2. Добавляет полоски к показателям, обложку и колонтитулы со сквозной нумерацией.
3. Блоки, не поместившиеся на лист при читаемом кегле, переносит на дополнительный лист. Порядок и три колонки сохраняются.

Оформление задают два файла:
- `doc.css` — лист A4, обложка, токены сайта;
- `classic.css` — стили для классов оригиналов: `card`, `metric-item`, `values-table`, `quarter`, `touchboard` и других.

**Чтобы поправить текст**, правьте оригинал в `showcase/` и пересоберите. Правки в `docs/*.html` перезапишутся.

```bash
node tools/restyle.mjs
```

```bash
node tools/docs.mjs
```

`restyle.mjs` пересобирает HTML (можно указать один: `node tools/restyle.mjs plasma`). `docs.mjs` проверяет каждый лист и пересобирает PDF: ничего не должно вылезать за край, налезать на колонтитул или не дотягивать по контрасту. Снимки листов он кладёт в `tools/out/docs/`.

Проверка полноты: все слова оригинала (с повторами) должны оказаться в документе.

```bash
node tools/docs-text.mjs
```

## Что где настраивается — `tools/restyle.config.mjs`

- обложка и подпись в колонтитуле;
- замены в тексте: «Уралметконструкция» → «Завод металлоконструкций», больше ничего не заменено;
- перенос блоков на дополнительные листы:
  - **инструкции** — первый лист оригинала разделён на «Коротко» и «Факты, готовность, риски», индексы вынесены на свой лист;
  - **третья инструкция** — «Цепочка развития» и «Что делать после 21 дня» перенесены в начало памятки;
  - **аватар** — по одному слою на лист, роли на двух листах;
  - **Plasma** — по разделу страницы на лист, индексы по два на лист;
- `tight` и `airy` — плотный и просторный варианты листа для тех, где текста чуть больше или заметно меньше, чем места.
