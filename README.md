# HTDC — лендинг

Лендинг организационной диагностики HTDC. Сам сайт — чистые HTML/CSS/JS без сборки: откройте `index.html` или поднимите любой статический сервер.

```bash
python -m http.server 8765
```

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная: вступление из четырёх экранов, ситуации, принципы, процесс, форматы, короткие блоки инструментов и истории, вопросы, заявка. |
| `tools.html` | Страница «Инструменты»: полные описания и все примеры. |
| `history.html` | Страница «История подхода»: хроника из шести периодов. |
| `styles.css`, `main.js` | Общие для всех страниц. В `main.js` живут туман и сфера на WebGL, вступление с автолистанием, шапка, ситуации, сцена раскрытия, форма. |
| `example.html` | Страница просмотра демонстрационных примеров: `example.html?doc=<id>`. |
| `showcase/docs/` | Оформленные документы витрины и их PDF. Именно они открываются на сайте. |
| `showcase/` | Оригиналы методолога (источник для сборки), `examples.js` с реестром примеров, `previews/` со снимками листов. |
| `policy.html` | Заглушка политики конфиденциальности. |
| `DIRECTION.md` | Идея, визуальный язык, ключевые решения. |
| `DRAFTS.md` | Черновики, которые нужно заменить перед запуском. |
| `htdc_landing_prompt.md`, `reference/` | Бриф и исходные материалы. |
| `tools/` | Тесты и служебные скрипты. Сайту не нужны. |

Адрес отправки формы — константа `FORM_ENDPOINT` в начале `main.js`. Пока она `null`, отправка имитируется.

## Тесты и инструменты

Нужны Node 20+ и установленный Chrome или Edge. Зависимость одна — `puppeteer-core`, она управляет системным браузером.

```bash
npm install
```

```bash
npm test
```

Что проверяет `npm test`:
- **статика:** якоря и локальные файлы на всех страницах, отсутствие жаргона методологии, обещаний результата и длинных тире в текстах, согласие по 152-ФЗ, целостность витрины;
- **браузер на трёх ширинах** (1440, 820, 375), главная и обе внутренние страницы: ошибки консоли, горизонтальная прокрутка, длина заголовков, загрузка картинок, размер кнопок, **контраст текста по пикселям** — текст прячется, и замеряется то, что реально под ним: туман, свет сферы, плашки;
- **поведение:** обход с клавиатуры и видимость фокуса, ситуации, форма, путь сферы (справа во вступлении, слева у принципов, за отмеченным пунктом), вступление (автолистание, доводка до экрана, полоски), меню на телефоне, переходы между страницами, просмотр примеров и PDF;
- **режим без анимации** (`prefers-reduced-motion`).

Остальное:

```bash
npm run previews
```

Пересобирает превью витрины из оформленных документов в `showcase/docs/`. Запускайте после пересборки документов или правки реестра `showcase/examples.js`. Сами документы и PDF собирают `node tools/restyle.mjs` и `node tools/docs.mjs` (подробности в `showcase/docs/README.md`).

```bash
node tools/perf.mjs
```

Стоимость кадра на видеокарте этого компьютера.

```bash
node tools/shots.mjs desktop
```

Скриншоты секций в `tools/out/`. Вместо `desktop` можно `phone`, следом можно назвать страницу и цели: `node tools/shots.mjs phone history.html` или `node tools/shots.mjs desktop intro:2 "#approach"`.
