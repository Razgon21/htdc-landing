# HTDC — лендинг

Лендинг организационной диагностики HTDC. Прототип: чистые HTML/CSS/JS, без сборки.

- `htdc_landing_prompt.md` — бриф.
- `reference/` — исходные материалы методолога (ТЗ, промпт, прототип). Сырьё, не спецификация.

## Запуск

Открыть `index.html` в браузере или поднять любой статический сервер:

```bash
python -m http.server 8000
```
