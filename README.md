# HTDC — лендинг

Лендинг организационной диагностики HTDC. Сам сайт — чистые HTML/CSS/JS без сборки: откройте `index.html` или поднимите любой статический сервер.

```bash
python -m http.server 8765
```

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html`, `styles.css`, `main.js` | Лендинг. В `main.js` — туман и сфера на WebGL, ситуации, сцена раскрытия, форма. |
| `example.html` | Страница просмотра демонстрационных примеров: `example.html?doc=<id>`. |
| `showcase/` | Документы методолога как есть. `examples.js` — реестр примеров витрины, `previews/` и `pdf/` — сгенерированные превью и PDF. |
| `policy.html` | Заглушка политики конфиденциальности. |
| `DIRECTION.md` | Идея, визуальный язык, ключевые решения. |
| `DRAFTS.md` | Черновики, которые нужно заменить перед запуском. |
| `htdc_landing_prompt.md`, `reference/` | Бриф и исходные материалы. |
| `tools/` | Тесты и служебные скрипты. Сайту не нужны. |

Адрес отправки формы — константа `FORM_ENDPOINT` в начале `main.js`. Пока она `null`, отправка имитируется.

## Тесты и инструменты

Нужны Node 20+ и установленный Chrome или Edge. Зависимость одна — `puppeteer-core`, она управляет системным браузером.

```bash
npm install
```

```bash
npm test
```

Что проверяет `npm test`:
- **статика:** якоря и локальные файлы, отсутствие жаргона методологии и обещаний результата в текстах, согласие по 152-ФЗ, целостность витрины;
- **браузер на трёх ширинах** (1440, 820, 375): ошибки консоли, горизонтальная прокрутка, длина заголовков, загрузка картинок, размер кнопок, **контраст текста по пикселям** — текст прячется, и замеряется то, что реально под ним: туман, свет сферы, плашки;
- **поведение:** обход с клавиатуры и видимость фокуса, ситуации, форма, переход сферы туда и обратно, просмотр примеров и PDF;
- **режим без анимации** (`prefers-reduced-motion`).

Остальное:

```bash
npm run previews
```

Пересобирает превью и PDF витрины из документов в `showcase/`. Запускайте после правки документов или реестра `showcase/examples.js`.

```bash
node tools/perf.mjs
```

Стоимость кадра на видеокарте этого компьютера.

```bash
node tools/shots.mjs desktop
```

Скриншоты секций в `tools/out/` (вместо `desktop` можно `phone`).
